# テニスの王子様 公式書アーカイブ

《网球王子》公式书信息收录网站，支持角色多版本对比、学校信息浏览、数据导入导出。

## 功能特点

- 📖 **角色对比**：同一角色在不同公式书版本间左右滑动对比
- 🏫 **学校信息**：点击学校卡片查看详细资料
- ✏️ **灵活编辑**：固定字段预填可修改，支持自定义字段
- 💾 **数据管理**：JSON 格式导入导出，本地存储

## 预置角色

- 越前リョーマ（10.5 / 20.5）
- 跡部景吾（10.5 / 20.5）

## 预置学校

青春学園、氷帝学園、立海大附属、四天宝寺、不動峰、山吹中学、六角中学、聖ルドルフ

## 技术栈

- 纯 HTML/CSS/JavaScript
- LocalStorage 本地存储
- GitHub Pages 部署
