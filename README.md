🎾 网球王子 - 公式书资料数据库 (Tenipuri Archive)
这是一个专为《网球王子》粉丝打造的公式书信息收录与角色设定管理网站。采用黑白复古漫画风设计，支持全平台（PC/手机）响应式访问，完全运行于浏览器本地，具备零成本部署、隐私保护与数据可移植性。
🌟 核心功能一览
 * 学校管理：查看并编辑各校公式书图集（支持多张上传）、学校地图及学校活动时间线。
 * 王子个人档案（多版本支持）：收录基本资料，支持对同一项目追加不同公式书版本（如：喜欢的颜色：红 [10.5]，蓝 [20.5]）。
 * 五维能力图表对比：基于 Chart.js 实现多版本公式书身体素质五维雷达图同屏叠加对比，并提供单项点评与综合评价。
 * 多维时间轴：内置“学校生活一日时间轴”、“休息日时间轴”以及“个人履历历史时间轴”，支持自由追加与修改。
 * 官方经典板块全收录：涵盖性格分析、他人评价、奇闻趣事、王子自述 (Q&A)、官方/许斐刚访谈、随身物品检查等。
 * 自定义 OC 角色追加：可在任意学校按照原作同样格式创建并管理自己设定的原创角色（OC）。
 * 自定义板块扩展：支持在任意角色页面底部自由追加多个自定义内容模块。
 * 纯前端本地持久化与数据导入导出：数据实时保存在浏览器 localStorage 中；支持一键导出/导入 JSON 文件进行备份或跨设备迁移。
 * 移动端抽屉适配：侧边栏支持手机端顺畅切换学校与王子列表。
📖 使用指南
1. 浏览与角色选择
 * 侧边栏导航：点击侧边栏中的学校名称可查看学校概要；点击角色名字进入角色详细资料页。
 * 手机端操作：在移动端访问时，点击顶部导航栏的 “学校/角色列表” 按钮即可展开抽屉菜单。
2. 资料修改与保存
 * 编辑数据：直接在输入框或文本域中修改任意数据（如时间轴、点评、基本资料等）。
 * 追加版本记录：在“喜欢的颜色”等项目下方点击 +追加版本记录，可录入不同公式书版本的具体内容。
 * 保存修改：修改完成后，点击页面右上角的 “保存数据” 按钮即可更新本地缓存。
3. 多版本五维图操作
 * 在“管理五维图数据集”区域点击 +追加公式书版本五维，输入该版本的名称（如 40.5）及各项数值（0-7），雷达图将自动更新并叠加对比。
4. 图像上传与注意事项
 * 支持区域：学校公式书扫描件、学校地图、随身物品图片、公式书原页图集均支持本地上传。
 * 文件大小限制：由于数据存储于浏览器本地（localStorage），单张图片大小请控制在 2MB 以内。上传前建议进行适当裁剪或压缩，避免导致浏览器存储空间溢出。
5. 自定义角色与自定义板块
 * 添加 OC 角色：点击侧边栏学校标题旁边的 +角色 按钮即可在该校下新建人物。
 * 删除角色：原创角色右上角有 OC 标识，点击页面右上角的 删除角色 即可彻底清除。
 * 追加板块：拉至角色页面最下方，点击 +追加自定义板块 可自由创建个性化模块。
6. 数据备份与迁移 (JSON)
 * 导出备份：点击侧边栏顶部的 “导出JSON”，将所有学校和角色数据下载到本地文件。
 * 恢复/导入数据：点击 “导入JSON”，选择之前导出的文件，即可恢复或迁移数据。
🛠️ 技术栈
 * 前端框架：Vue.js 3 (Options API / CDN)
 * CSS 框架：Tailwind CSS (CDN)
 * 图表渲染：Chart.js (Radar Chart)
 * 数据存储：Web Storage API (localStorage) + JSON 文件序列化
